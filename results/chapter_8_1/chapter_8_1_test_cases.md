## 8.1.1 Overview and Verification Methodology

The test cases presented in Table 8.1 evaluate the end-to-end functionality of DeepWAF-XAI across all 23 functional security modules specified in the MCA Project Black Book. Testing was executed empirically against live system components without synthetic mocking.

Special attention was directed toward resolving two previously documented failure modes:
1. **Raw IP Banking Endpoint Inspection (Step 16):** Misclassification of raw-IP URLs targeting banking endpoints due to lack of IP samples in the BiLSTM training corpus.
2. **Model Sequence Length Post-Truncation Evasion (Step 75):** Bypassing of the character-level neural network via leading benign padding that pushed malicious attack payloads beyond the 200-character sequence horizon.

Both failure cases were root-caused, corrected via architectural perimeter and sliding-window enhancements, rigorously regression-tested across 27 distinct test vectors, and retested to empirical verification.
